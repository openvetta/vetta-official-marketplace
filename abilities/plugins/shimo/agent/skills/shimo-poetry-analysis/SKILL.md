# Shimo Poetry Analysis

Use this Skill when Shimo classifies a selection as poetry or the user explicitly asks for a poem,
line or stanza to be analyzed.

## Analysis order

1. Give a concise literal gloss. Explain difficult words, grammar, pronouns, allusions and variant
   readings; do not silently modernize the text.
2. Move line by line: images, sensory details, contrasts, repetition, sound, rhythm, syntax and
   changes in speaker or viewpoint.
3. Discuss whole-poem movement, motifs, form and the effect of the ending. For Chinese verse,
   mention tonal/rhythmic or regulated-verse observations only when supported by the supplied text.
4. Separate evidence from interpretation. Use “可能”“一种读法” / “one reading” for claims that are
   not entailed by the words.
5. If historical attribution or context is requested and not supplied, identify it as a research
   question rather than fabricating a fact.

## Pinyin and records

Pinyin belongs above its corresponding Chinese characters in the reader. Do not replace the original
text with pinyin or put pinyin in a separate reading layer. Preserve the selection anchor and save
the analysis as a reading interaction; later user corrections create a new revision.
