# 拾墨（Shimo Reader）

> **为主动学习而设计的安静阅读器 · AI 驱动的个人深度研读与知识资产工作台**
> *AI-Augmented Deep Reading & Study Hub for Active Learning*

---

## 📖 产品定位与核心哲学

拾墨（Shimo）不是一个普通的 Office 协同编辑器，也不是冷冰冰的格式转换查看器。它的本质是**一个立足于“本地优先（Local-first）”与“主动学习（Active Learning）”理念的 AI 个人深度研读与知识资产工作台**。

它旨在打破传统电子书“只看不思、划线即忘”的浅层阅读模式，以及外部 Chatbot“复制粘贴大段文本、频繁跳出打断心流”的繁琐流程，让读者在纯粹安静的阅读环境中，拥有一个随时在侧的 AI 研读导师。

### 核心设计原则

1. **私有副本与离线优先（Private & Sovereign）**
   - 导入的 PDF、Markdown、TXT 会完整复制到插件私有存储中，实现纯离线阅读。
   - 所有的划线高亮、手记感想、AI 解析与问答记录，均以原子级锚点（Anchor）持久化于本地结构化存储，支持完整导出，**数据资产 100% 归读者所有**。

2. **极简静默与渐进披露（Quiet & Progressive Disclosure）**
   - 常态阅读时，界面完全后退，杜绝任何喧宾夺主的弹幕、红点或浮夸装饰，给读者留出最大程度的文字呼吸感与专注心流。
   - **只有当读者主动划选文本时**，专属认知支架浮动坞才轻盈浮现，实现真正的“不扰即自由”。

3. **体裁自适应的认知脚手架（Cognitive Scaffolding）**
   - **古典诗赋典籍**：自动识别律绝赋体，提供意象解析、名句典故考据、逐句赏析与拼音覆载；
   - **现代深度长文 / 论文报告**：精准拆解论证链条，提取核心主张与推导前提，支持费曼通俗重述与专业术语精解；
   - **大部头书籍**：辅助串联跨章节上下文关联、梳理人物关系与动机、提炼全局核心主题。

4. **读思一体与双向锚定（In-situ Annotation）**
   - AI 不是割裂的外部聊天窗口，而是“坐在身边的陪读教练”。每一次划词提问与解答，均以字符偏移或 PDF 页码范围为物理锚点，永久烙印在原书对应位置，构建可回溯的立体读书脉络。

## 🏛️ 双态研读工作台架构

拾墨采用**宏观资产总览**与**微观沉浸研读**无缝结合的双态工作台体系：

```text
 ┌──────────────────────────────────────────────────────────────┐
 │  模式 1：书架与研读总览（Library Overview Hub）                 │
 │  · 顶部全景资产徽标（文稿数 · 研读笔记数 · AI 精析次数）          │
 │  · 继续研读卡片（最近活跃文稿、阅读进度与快速续读）               │
 │  · 藏书全景书架（网格 / 列表双模、即时检索、体裁分类过滤）         │
 │  · 全局研读时光流（跨文档聚合的所有高亮、手记与 AI 问答）         │
 └──────────────────────────────┬───────────────────────────────┘
                                │ 点击任意文稿或笔记卡片
                                ▼
 ┌──────────────────────────────────────────────────────────────┐
 │  模式 2：沉浸阅读器（Deep Reading View）                     │
 │  · 顶部面包屑常驻 [ ← 返回总览 ] 导航                          │
 │  · 多格式渲染（PDF / Markdown / TXT）、大纲目录与阅读进度追踪   │
 │  · 就近划词浮动坞（Selection Toolbar）与极简提问/笔记抽屉       │
 │  · 侧边资料库（LibrarySidebar）与本篇阅读记录面板（RecordsPanel） │
 └──────────────────────────────────────────────────────────────┘
```

### 1. 书架与研读总览（LibraryOverview）
- **继续研读（Continue Reading）**：自动提取最近活跃阅读的文稿，呈现进度与格式徽标，一键续读；
- **藏书全景（All Materials Shelf）**：支持网格（Grid）与紧凑表格（List）切换，按诗歌/文章/书籍进行体裁过滤，内嵌全库模糊搜索；
- **全局研读时光流（Global Insights Stream）**：打破单文档壁垒，将全库分散的 AI 回答、批注与手记按时间倒序汇聚成时光流，支持点击任一记录“一键穿梭回正文对应位置”；
- **全局文件导入（Drop Target）**：随时拖入 PDF、Markdown、TXT 建立新私有副本。

### 2. 沉浸研读器（ReadingSurface）
- **极简现代界面**：去除伪古风和冗余装饰线，采用现代高可读性字体排版（诗歌采用衬线雅宋，长文采用清晰黑体）；
- **AI 交互重塑**：优化的提问弹窗（`QuestionComposer`），内置一键常用提示词 Chips（“解释深层含义”、“总结论据”、“通俗重述”），清晰区分引文卡片与输入框，杜绝机器字段泄漏；
- **自由返回**：正文顶部左侧常驻返回总览入口，随时在全景书架与单篇研读间无缝穿梭。

## 🧩 技术架构与模块划分

```text
src/
├── domain.ts               # 核心领域 Schema：材料元数据、阅读锚点、记录结构、阅读偏好
├── classification.ts      # 体裁判定策略（诗赋/文章/书籍）与动作映射（ACTIONS）
├── repository.ts          # 基于 PluginStorageApi 的私有副本、记录与缓存持久层
├── runtime.ts             # 插件运行时事件总线（材料切换、记录更新广播）
├── index.tsx              # 插件入口，注册 Workspace 视图、Activity 面板与上下文菜单
└── reader/
    ├── useReaderController.ts   # 阅读状态机（当前文档、选区、笔记流、进度控制）
    ├── prompts.ts               # AI 提示词工程模板（古典赏析、深度解析、意象萃取）
    ├── components/
    │   ├── LibraryOverview.tsx  # 书架与研读总览主工作台
    │   ├── LibrarySidebar.tsx   # 侧滑资料库抽屉（极简列表模式）
    │   ├── ReadingSurface.tsx   # 阅读载体总装配层（分流总览态与阅读态）
    │   ├── ReaderHeader.tsx     # 顶部控制栏与导航面包屑
    │   ├── QuestionComposer.tsx # 现代化 AI 划词提问弹窗
    │   ├── NoteComposer.tsx     # 现代化手记/感想记录弹窗
    │   ├── SelectionToolbar.tsx # 划词后就近浮动操作坞
    │   ├── RecordsPanel.tsx     # 当前文档侧栏阅读记录瀑布流
    │   ├── MarkdownReader.tsx   # Markdown 增强渲染器（注音、KaTeX 数学公式）
    │   ├── PdfReader.tsx        # PDFCanvas 渲染与划词高亮层
    │   └── TextReader.tsx       # TXT 纯文本高性能排版
    └── test/                    # 单元与端到端模拟测试夹具
```

### 内置 Agent Skills
插件自带 3 个由 Vetta 托管的协同研读 Skill：
- **`shimo-reading-coach`**：长文与通用研读教练，分层解析结构与论据；
- **`shimo-poetry-analysis`**：古典诗赋专属解析器，考据典故、字调意象；
- **`shimo-reading-records`**：阅读记录检视与关联，辅助读者回顾与整理认知资产。
