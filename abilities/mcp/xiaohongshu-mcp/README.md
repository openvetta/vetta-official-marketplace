# Xiaohongshu

Official Xiaohongshu automation MCP server from [xpzouying/xiaohongshu-mcp](https://github.com/xpzouying/xiaohongshu-mcp).

Install this Ability in Vetta to run the upstream release binary over stdio. Use the server's `get_login_qrcode` tool for the first login; cookies are stored in Vetta-managed Ability data.
