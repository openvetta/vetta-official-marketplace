# 拾墨集成说明

拾墨（Shimo）是 Vetta 的沉浸式中英文阅读工作区。本 Bundle 把拾墨阅读器（内含阅读引导、诗句解析、
阅读记录三个 Shimo 专属 Skills）与已有的 PDF Toolkit 组合在一起。

## 范围

- 支持中文、英文和混合资料的 PDF、Markdown、TXT。
- 导入资料时复制到私有资料库；资料副本、记录和已缓存拼音可离线阅读。
- 渐进式披露：划选后才出现当前类别的操作，正文页面保持安静。
- 提问复用 Vetta 现有对话区。拾墨不实现第二套聊天 UI、消息列表、队列、模型选择或流式协议。
- PDF 高亮、批注、sidecar 记录和带标注 PDF 导出由拾墨插件负责。
- OCR 通过 Vetta 的 `ocr` 协议使用，默认调用宿主内置本地 Provider。

## Bundle 成员

- **拾墨阅读器**：阅读工作区、资料库、选择操作、拼音、记录和导出；插件内置阅读引导、诗句解析、阅读记录 Skills。
- **PDF Toolkit**：已有的 PDF Agent 工作流，不是拾墨阅读器的实现依赖。

远程 OCR 不随 Bundle 提供。open-vetta 宿主负责协议和 Provider Registry；未来可由独立插件实现某个
Provider 或聚合服务。本市场包不包含厂商适配器、API Key 表单或真实远程 OCR 调用。

## 数据与隐私

导入时把资料字节复制到拾墨私有存储，日常阅读不依赖原始路径。OCR 输入由 Vetta 控制为不透明句柄。
内置本地 OCR 不会上传资料。未来安装的远程 Provider 必须声明权限、允许域名和配置状态，只有在 Agent
配置中明确选择后才会使用。

AI 回答默认自动保存。编辑或重新生成会创建新的阅读记录 revision，不覆盖 Vetta 原始会话消息。
